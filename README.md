Open-source symbolic computing and data science packages for the Mojo programming language. We started with [functional programming fundamentals](https://github.com/Spellbound-Mojo/fp_mojo). Then we will next move to arbitrary-precision numeric library, relational e-matching, and other core CAS components. Our CAS focus is primarily probability theory and statistics, but over time we will try to grow in all directions depending on user feedback.

Each component is released as its own package for modularity and maintainability, and some may be useful in their own right.
